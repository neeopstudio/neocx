# NEOCX — HTML Workspace

NEOCX adalah workspace HTML interaktif untuk menulis, mengimpor, menjalankan, dan melihat preview kode HTML secara langsung. Dibangun dengan antarmuka mobile-friendly, pilihan tema dark dan cream, serta pengalaman Progressive Web App (PWA) yang dapat dipasang di perangkat dan mendukung penggunaan offline setelah pemuatan awal.

**GitHub repository description:**
`Interactive HTML workspace with live preview, file import, dark/cream themes, animated UI, and installable offline-ready PWA.`
